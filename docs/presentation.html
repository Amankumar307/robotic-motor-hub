STAGE 1 : PROJECT INTRODUCTION & MOTIVATION STAGE 1 OF 6

Stage 1: Industrial Motivation & Problem Statement

🤖 Industrial Motivation
  • Multi-DoF Robotic Systems: 6-axis articulated arms, 3-axis Cartesian gantries, and AGV differential pods.
  • Precision Coordination: Stepper and BLDC motors must track synchronized trajectories without drift.
  • Applications: High-speed pick-and-place, CNC milling, laser cutting, and semiconductor wafer handling.
⚠️ Problem Statement
  • User-Space Jitter: Standard Linux lacks real-time determinism, leading to motor vibration and path error.
  • Hardware Abstraction Gap: Disconnect between user-space trajectory planning and hardware silicon registers.
  • Safety Hazards: Mechanical stalls and limit strikes demand sub-millisecond emergency stop reactions.
🎯 Project Objectives
  • Linux Character Driver: /dev/motor_hub with MMIO register layout and 1 kHz hrtimer interrupts.
  • Deterministic C++ Daemon: 1000 Hz loop under POSIX SCHED_FIFO with zero heap allocation in loop.
  • Closed-Loop Algorithms: Anti-windup discrete PID and multi-axis synchronized trapezoidal velocity profilers.

STAGE 3 : HARDWARE-SOFTWARE CO-DESIGN STAGE 3 OF 6

Stage 3: MMIO Register Map & State Machine

💾 32-Bit MMIO Register Bank (Per Axis)
  • 0x00 - REG_AXIS_CTRL: Enable (b0), Reset (b1), E-Stop (b2), Home (b3).
  • 0x04 - REG_AXIS_STATUS: Enabled, InPosition, Error, Limits Hit, E-Stop Active.
  • 0x08 - REG_TARGET_POS: Desired quadrature encoder position (signed 32-bit).
  • 0x0C - REG_ACTUAL_POS: Measured encoder position feedback (signed 32-bit).
  • 0x10 - REG_TARGET_VEL: Commanded target velocity (ticks/second).
  • 0x14 - REG_ACTUAL_VEL: Measured continuous velocity feedback.
  • 0x18 - REG_PWM_OUTPUT: Commanded motor duty effort (-1000 to +1000).
  • 0x1C-0x24 - REG_KP / KI / KD: Discrete PID gains (fixed-point Q16.16).
🔄 Actuator Finite State Machine (FSM)
  • UNINITIALIZED: Initial boot state prior to self-test.
  • IDLE: Driver initialized, drive energized, waiting for commands.
  • HOMING: Seeking limit switch reference and zeroing coordinates.
  • POSITIONING: Executing real-time synchronized trajectory moves.
  • JOGGING: Open-loop or constant velocity manual jogging.
  • ERROR: Tracking error stall or overtemperature detected.
  • EMERGENCY_STOP: Immediate hardware PWM cutoff latched.

STAGE 5 : TESTING & INTEGRATION STAGE 5 OF 6

Stage 5: Real-Time Motion Control Algorithms

🧮 Anti-Windup Discrete PID Controller
  • Discrete Math: \( u[k] = K_p e[k] + K_i \sum e[k]\Delta t + K_d \frac{\Delta e}{\Delta t} \)
  • Anti-Windup Clamping: Clamps accumulated integral to ± 250 to prevent huge overshoots during motor saturation.
  • Filtered Derivative: Discrete low-pass filter (α = 0.7) eliminates high-frequency encoder noise chatter.
  • Deadband Handling: Zeroes PWM hunting jitter when within ± 5 ticks of setpoint.
📈 Synchronized Trajectory Planner
  • Trapezoidal Velocity Planning: Calculates acceleration (\(t_a\)), cruise (\(t_c\)), and deceleration (\(t_d\)) phases.
  • Triangular Adaptation: Automatically handles short moves where max cruise velocity cannot be reached.
  • Synchronized Multi-Axis Scaling: Calculates \(T_{max}\) across all axes, then scales velocities and accelerations so all axes start and finish in lockstep.
STAGE 5 : IPC & REAL-TIME SAFETY STAGE 5 OF 6

Stage 5: High-Speed IPC & Real-Time Safety Watchdog

🚀 Zero-Copy POSIX Shared Memory IPC
  • shm_open() & mmap(): Creates shared memory segment /dev/shm/motor_hub_telemetry.
  • Zero-Copy Streaming: 1 kHz daemon publishes telemetry without kernel copying overhead (< 2.1 µs latency).
  • Cache-Line Alignment: Decorated with alignas(64) to prevent false sharing between CPU cores.
  • Command Queue: Asynchronous FIFO channel for operator move/home/estop commands.
🛡️ Failsafe Watchdog Supervision
  • Heartbeat Deadline: Monitors periodic loop deadlines; missing 150 ms deadline triggers instant E-Stop.
  • Tracking Error Threshold: Detects mechanical stalls if \( |target - actual| > 35,000 \) ticks.
  • Thermal Trip: Trips E-Stop if axis temperature exceeds 80°C.
  • Instant Cutoff: Motor PWM output clamped to 0 in < 0.05 ms upon fault.
